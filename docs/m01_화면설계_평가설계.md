## 7. 예시 산출물 주제

**데일리마켓 — 신선식품 온라인 쇼핑몰**

화면 설계는 특정 도메인 지식이 필요 없는 과목이므로, **누구나 아는 쇼핑몰**을 주제로 삼았다.
목록 · 상세 · 입력 폼 · 표 · 외부 연동(PG 결제) · 로그인 제약이 한 서비스 안에 모두 있어
화면 설계에 필요한 요소를 빠짐없이 보여 줄 수 있다.

학생은 각자 다른 주제(예약 서비스 · 도서관 · 배달 앱 등)로 같은 구조를 만들면 된다.

### 예시로 실제 작성한 것

| 과제 | 예시 산출물 | 제작 방식 |
|:--:|:--|:--|
| 1 | 요구사항 명세서 8행 (SR-01~08) — 유스케이스와 1:1 대응 | 표 · 실제 문장 |
| 1 | 유스케이스 다이어그램 — 액터 3 · 유스케이스 12 · include 6 · extend 1 · 일반화 1 · 범례 | SVG 직접 작도 |
| 1 | 유스케이스 명세서 2건 (장바구니 담기 / 주문·결제) | 표 · 정상·대안·예외 흐름 |
| 2 | 스타일가이드 6항목 + 지면 이미지 (로고·색 6칩·타이포 5단·버튼·수량 스테퍼·12컬럼) | SVG 직접 작도 |
| 3 | 화면 목록 5행 (내부 4 · 외부 1 = PG 결제창) | 표 |
| 3 | 화면 흐름도 · 메뉴 구조도 | SVG 직접 작도 |
| 3 | Figma 작업 화면 캡처 3종 (캔버스 · 화면 확대 · Prototype 패널) | SVG 직접 작도 |

별도 PNG 를 만들지 않고 **브라우저가 실제로 그리는 SVG** 파일로 넣는다.
합성 이미지가 아니며, 인쇄·확대에도 깨지지 않는다.

예시는 접힌 블록에 따로 두지 않고, **[예시 보기] 를 누르면 입력칸이 실제로 채워지고
드롭존에 그림이 들어간다.** DBMS 모듈 `SAMPLE_1` 의 「정답 보기」와 같은 방식이다.
예시 모드와 기본 모드의 **화면 스타일은 동일하다** — 예시 화면이 곧 완성된 제출서의 모습이어야 하기 때문이다.
