## 3. 유형별 hwp 구조 차이

| 항목 | A 포트폴리오 | B 평가자 체크리스트 | C 문제해결 시나리오 | D 혼합 |
|:--|:--|:--|:--|:--|
| 능력단위요소별 요구조건 칸 | 없는 것도 있음 (01) | 있음 (수행준거 전문) | 있음 | 있음 |
| 작업지시서 | 과제 나열형 | 「다음 각 문제를 해결」 + 내용(설명) 분리 | 시나리오 지문 + 문제 1~N | 문제별 유형 표기 |
| 채점표 블록 기준 | 과제 단위 | 능력단위요소 단위 | 능력단위요소 단위 | 유형별 분리 |
| 예시 자료 | `[예시]` 이미지 | 표 예시 (현행시스템 조사표 등) | 실행화면 캡처 | 혼재 |
| 제출물 | 산출물 파일 (PDF·Figma) | PPT 1파일 통합 | PPT + 소스 폴더 | PPT |
| 채점 주체 | 강사 (결과평가) | 강사 (과정평가) | 강사 (과정+결과) | 혼합 |
