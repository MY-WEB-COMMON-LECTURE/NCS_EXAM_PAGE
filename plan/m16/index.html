3. 교육목표 및 내용

교과목표
(총괄)		 공공데이터포털에서 확보한 데이터로 이진분류 모델을 학습하고, 그 모델을 API 로 서비스한 뒤 인증이 적용된 웹 화면에서 예측하고 그 이력을 데이터베이스로 관리하는 서비스를 구축할 수 있다.
세부
학습목표
  1. 공공데이터포털에서 분석 목적에 맞는 행 단위 데이터를 확보하고, 출처와 이용허락범위를 명시할 수 있다. 요소 ①
  2. 데이터의 구조와 품질을 진단하여 정제 방향을 세우고, 범주별 양성비율로 인사이트를 도출할 수 있다. 요소 ①
  3. 이진 타겟을 정의하고 데이터 누수가 되는 컬럼을 배제하여 독립변수를 선별할 수 있다. 요소 ①
  4. 데이터를 정제 · 가공하고 클래스 분포를 유지한 채 분할하여 모델을 학습시키고, 지표 선택의 근거를 서술할 수 있다. 요소 ②
  5. 모델과 입력 정의서를 저장하고 이를 API 로 서비스하며, 예측 이력의 생성 · 조회 · 수정 · 삭제를 구현할 수 있다. 요소 ②
  6. 컨테이너 기반으로 데이터베이스 · 서버 · 화면을 통합 구축하고, 인증이 적용된 서비스의 동작을 검증하여 결과를 해석할 수 있다. 요소 ②
